# 📚 Student Analysis System

A comprehensive Python-based student management application that demonstrates the use of core Python concepts including functions, lists, tuples, and dictionaries for complete student data analysis and management.

## 🎯 Overview

This project is a practical implementation of a student management system that allows users to perform various operations on student data. It's designed to showcase fundamental Python programming concepts while providing useful functionality for managing student records.

## ✨ Features

The system is organized into 7 distinct tasks, each focusing on different aspects of student data management:

- **Task 1**: Student data input and storage
- **Task 2**: Data retrieval and display operations
- **Task 3**: Student performance analysis
- **Task 4**: Grade calculation and categorization
- **Task 5**: Search and filter functionality
- **Task 6**: Statistical analysis of student data
- **Task 7**: Data export and reporting

## 🚀 Installation

1. Clone this repository:
```bash
git clone https://github.com/Arpit-07-Sahu/Python-Project-Student-Analysis-System.git
```

2. Navigate to the project directory:
```bash
cd Python-Project-Student-Analysis-System
```

3. Run any task file:
```bash
python Task1.py
```
